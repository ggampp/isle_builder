SALA DE JOGOS

Sandboxes construídos do zero em TypeScript + Three.js, sem engine de jogo no meio do caminho. Os mundos — terreno, água, casario e criaturas — são gerados em código. Escolha um e comece a construir. Na forja, cada cubo de uma arma voxel se encaixa no próximo.

Isle Builder

sandbox de pintura 2D

Um mar infinito e um pincel. Pinte areia, grama, pedra e trilhas em pixel art, deixe o autotiler costurar as bordas e veja o vilarejo ganhar vida sozinho — moradores caminham, barcos cruzam a costa e a fauna marinha nunca invade a terra.

  • 🖌️ pincel, linha, retângulo e balde
  • ↩️ undo & redo completos
  • 🏘️ 53 objetos para espalhar
  • 🐟 simulação de agentes

Canyon Rails

construtor de ferrovias 3D

Uma mesa desértica cercada por um rio turquesa. Assente trilhos peça a peça, dinamite as pedras do caminho, cruze o desfiladeiro numa ponte de cavalete que nasce sozinha e ligue as cidades — o trem cuida do resto.

  • 🛤️ trilhos peça a peça
  • 💣 dinamite e desvios
  • 📋 contratos e níveis
  • 🔊 áudio sintetizado
Jogar Canyon Rails ▶

Sprints 01–06 concluídas · jogo completo

Prisma

puzzle diário de luz

Um ateliê óptico 3D, com um tabuleiro novo por dia — igual para todo mundo. Gire espelhos para desviar os feixes até os alvos; dois feixes que se cruzam seguem misturados: é assim que se acende um alvo roxo, laranja ou verde.

  • 🔺 ateliê 3D
  • 🎨 mistura de cores
  • 🧩 sempre tem solução
  • 📆 desafio do dia
Jogar Prisma ▶

Jogo completo · puzzle diário e tabuleiros extras

Splinter

saloon voxel

Um pórtico de saloon feito de cubos. Atire nas portas e elas balançam na dobradiça; acerte a junta e o vão inteiro cai. Lanternas penduradas em correntes de aço, cinco armas, entulho de verdade.

  • 🔫 cinco armas
  • 🚪 dobradiças e correntes
  • 🧱 destruição voxel
  • 🌵 deserto jogável
Jogar Splinter ▶

Jogo completo · playground de destruição

Glint

vale de magia

Uma viajante pixelada num vale de brinquedo. Gaste mana num círculo mágico, derrube slimes e suba de nível — cada nível deixa o golpe mais forte, até o slime cair num único clarão.

  • ✨ magia e cutelo
  • 🟢 slimes e golém
  • 💎 cristais de descanso
  • 📈 level-up de verdade
Jogar Glint ▶

Jogo completo · action RPG no vale

Voxel Forge

gerador de armas

Uma forja de cubos. Troque lâminas, guardas, empunhaduras, pomos, hastes, cabeças de machado e maça — e misture tudo: punho de pistola num pique, machado num punho de espada, tridente com corrente.

  • ⚔️ peças intercambiáveis
  • 🪓 híbridos e tridentes
  • 🔗 trilhos e correntes
  • 🧱 um único HTML
Abrir Voxel Forge ▶

Arquivo único · cubos soldados na arma

Rodando na sua máquina

# Isle Builder
cd islebuilder && npm install && npm run dev

# Canyon Rails
cd railcanyon && npm install && npm run dev

# Prisma
cd prisma && npm install && npm run dev

# Splinter
cd splinter && npm install && npm run dev

# Glint
cd glint && npm install && npm run dev

# Voxel Forge (arquivo HTML único)
# abra voxelforge/index.html ou sirva a pasta

Cada jogo é uma aplicação Vite independente, com seus próprios testes (npm run test) e gate de tipos no build. A forja voxel é um único HTML, sem passo de build.
